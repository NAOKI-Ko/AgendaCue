AgendaCue プライバシーポリシー

施行日: 2026年8月22日

AgendaCueは、iPhoneのカレンダー予定を読み取り、予定前のアラームを設定するアプリです。

収集しない情報

AgendaCueにはアカウント、ログイン、広告、分析、トラッキング、開発者が運営するバックエンド、第三者SDKはありません。開発者がカレンダー内容を収集、送信、共有する仕組みはありません。

端末内での利用

カレンダー情報はAppleのEventKitを通じて、ユーザーが許可した範囲で読み取ります。予定情報はアラームを設定するために端末内で処理されます。使用するカレンダー、アラームの時間、予定ごとの設定などは端末内に保存されます。AgendaCueはカレンダー予定を追加、変更、削除しません。

権限

カレンダーとアラームへのアクセスはiOSの権限機能で管理され、ユーザーはiOSの「設定」から変更できます。
