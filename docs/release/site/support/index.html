AgendaCue サポート

AgendaCueは、iPhoneのカレンダー予定を読み取り、選んだ時間前にAlarmKitのアラームを設定します。

対応環境

iOS 26以降のiPhone。iPhoneのカレンダーに登録され、EventKitから取得できる時間指定予定が対象です。

よくある確認事項

  • カレンダーへのアクセス: iOSの「設定」でAgendaCueのカレンダーアクセスを許可してください。
  • カレンダーが表示されない: AgendaCueの「設定」から「表示するカレンダー」を開き、使用するカレンダーが有効か確認してください。
  • アラームへのアクセス: iOSの「設定」でAgendaCueのアラームアクセスを許可してください。
  • アラームが設定されない: 使用するカレンダーと予定ごとのアラーム設定を確認してください。終日予定と、アラーム時刻がすでに過ぎた予定は対象外です。
  • 予定を変更した: AgendaCueを前面に戻すと、最新のカレンダー状態を確認します。
  • 権限を拒否・取り消した: アプリ内の案内からiOSの「設定」を開いて復旧できます。

V1の制限

カレンダーは読み取り専用です。外部カレンダーサービスへ直接接続する機能、アカウント、バックエンド、独自通知、スヌーズ、任意分数の設定、watchOSアプリはありません。バックグラウンド更新の実行時刻はiOSが管理します。
