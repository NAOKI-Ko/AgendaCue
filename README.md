# Calendar Alarm

Calendar Alarm is a planned iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 specification baseline and a disposable WU-00 EventKit/AlarmKit feasibility target. Start with [docs/START_HERE.md](docs/START_HERE.md). The WU-00 Human Device Gate is pending; no Production feature implementation has started.
