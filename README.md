# Calendar Alarm

Calendar Alarm is a planned iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 specification baseline, a disposable WU-00 feasibility target, and the WU-01 Product foundation. Start with [docs/START_HERE.md](docs/START_HERE.md). Device verification remains deferred to the consolidated WU-10 Human Gate; no such behavior is recorded as passed.
