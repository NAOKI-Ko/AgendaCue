# Calendar Alarm

Calendar Alarm is a planned iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 implementation baseline through WU-08 Reliability. Start with [docs/START_HERE.md](docs/START_HERE.md). Device and actual system-scheduled background verification remain deferred to the consolidated WU-10 Human Gate; no such behavior is recorded as passed.
