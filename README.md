# Calendar Alarm

Calendar Alarm is a planned iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 implementation baseline through WU-09-03 Today Visual Source of Truth Correction Pass. Start with [docs/START_HERE.md](docs/START_HERE.md). Real-device, VoiceOver, release identity/assets/metadata, and actual system-scheduled background verification remain deferred to the consolidated WU-10 gate; no such behavior is recorded as passed.
