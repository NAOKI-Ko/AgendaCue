# AgendaCue

AgendaCue is an iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 candidate at WU-10 Release Gate Phase A. Start with [docs/START_HERE.md](docs/START_HERE.md) and the required [Human Gate checklist](docs/release/HUMAN_GATE_CHECKLIST.md). Automated audit is complete, but Production identity/signing inputs and explicit real-device/owner evidence remain required; the release is not complete.
