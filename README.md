# Calendar Alarm

Calendar Alarm is a planned iOS 26+ app that turns selected device-calendar events into prominent, user-configured AlarmKit alarms.

This repository contains the Production V1 specification baseline through WU-04 Alarm Scheduling. Start with [docs/START_HERE.md](docs/START_HERE.md). Device verification remains deferred to the consolidated WU-10 Human Gate; no such behavior is recorded as passed.
